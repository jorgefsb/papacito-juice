# Roadmap

[Español](roadmap.md) · [English](roadmap.en.md)

Stable has four levels: Nada, Poquito, Mucho, Hardcore. The following is a proposal, not implemented and not a fifth level in this version.

## Proposal: “Legendario”

**Idea.** The environment responds to useful actions. When the person completes something valuable (submits a form, finds Mokis, finds what they need), that area gives a short visual response and context-sensitive celebration.

**In this profile**

- Moki participates only here, in the personal brand, with authorized artwork and existing poses. Generic Game Feel adds no mascot.
- Cursor radius stays bounded by Hardcore’s 18 px.
- Renderer algorithm/GPU work stay unchanged; approved Cursor líquido renderer remains byte-identical.
- Reduced motion disables effects.
- Nothing blocks navigation, clicks, scroll or keyboard.

**Conditions to move beyond proposal**

1. Human tests demonstrating smiles or repeated gestures.
2. New juice version supporting it without editing 1.2.0.
3. Automated tests of non-obstruction, reduced motion and bounded work.
4. Brand-owner approval.

## Known gaps

- A documented juice switch to stop the old Hardcore trail instead of CSS-hiding it.
- Publish Game Feel 1.0.1 and Cursor líquido 1.0.1 releases so setup does not require local paths.

## Status of this documentation review

The list above preserves starting-point gaps; it does not verify current remote release availability. This review publishes nothing. If a download fails, use verified local paths from the integration guide without changing pins.
