# Papacito Juice: demostración explicada

[Español](README.md) · [English](README.en.md) · [← README](../../README.md)

[MP4](demo.mp4) · [GIF](demo.gif) · [Captions ES](demo.es.vtt) · [Captions EN](demo.en.vtt) · [Player](player.html)

Grabación existente reutilizada sin modificar: 18.44 s, H.264, 1280 × 900, 25 fps, sin pista de audio. Los captions son descripción editorial, no transcripción de una voz inexistente.

Fuente reproducible: `scripts/capture-demo.mjs`, página `examples/`, eventos reales de puntero en Chromium + SwiftShader. Los PNG/GIF/MP4 originales permanecen iguales al baseline. No se simula tinta ni se altera el presupuesto del motor. No demuestra rendimiento de teléfono físico.

## Transcripción descriptiva

- **0–2 s:** Demo local de marca personal: Moki real y acciones de página.
- **2–5 s:** Se encuentran los Mokis del día y se abre Hardcore.
- **5–13 s:** Juega cambia el nivel; el puntero dibuja la estela real.
- **13–18.44 s:** Hardcore: fluido más amplio; las acciones siguen disponibles.
